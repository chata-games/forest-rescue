# Heartwood gate landmark

Ancient friendly living-tree gate with a warm doorway, layered roots, emerald leaves, violet flowers, and restrained cyan runes. Match the defended gate in the Forest Rescue gameplay concept.

- Transparent background
- 512x768, one complete vertical gate
- Front-facing with a slight top-down three-quarter view
- Crisp silhouette at about 240x440 display size
