# Battle controls

Generated with the built-in imagegen tool. The loadout reference at
`docs/design/loadout-screen/field-satchel-reference.png` supplied the material
style. Labels and icons are live HTML. Existing loadout card and parchment art
is reused with these assets.

## Dark panel

Saved as `assets/ui/battle-panel.png`.

Use case: stylized-concept. Asset type: reusable empty in-game HUD panel for Forest Rescue. Generate one rectangular dark carved oak plate, straight-on orthographic, 3:1 width to height, filling the image edge to edge. Match reference woodland inventory UI materials. Very thin aged brass double border within outer 4 percent, tiny understated turquoise corner inlays, slight moss at corners only. Center 90 percent quiet very dark brown oak, subtle fine horizontal wood grain for live cream HTML labels. Flat even lighting; high-quality painted fantasy game art. Opaque rectangular asset, no surrounding background or margins, no words, numbers, icons, characters or watermark. Must remain readable at small size and suitable for CSS background stretched to compact HUD chips.

## Primary action

Saved as `assets/ui/battle-action.png`.

Use case: stylized-concept. Asset type: reusable empty primary action button background for Forest Rescue in-game HUD. One very wide rectangular gold button plate, 3:1 width to height, front orthographic view filling canvas edge to edge. Match supplied loadout brass and carved woodland inventory style. Warm luminous but not glowing golden hammered metal center, very quiet fine texture to support dark live HTML text. Slim dark oak outer edge and aged brass bevel within outer 6 percent; restrained engraved leaf tips at corners, tiny cyan inlay at each far end. No large ornaments, no surrounding scene, no lettering, text, symbols, logo or watermark. Opaque background. Clear gold center 85 percent empty. Painted fantasy game asset, usable at small touch-button size.
